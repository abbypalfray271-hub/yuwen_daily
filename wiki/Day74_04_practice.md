# 巩固训练：《森林翼龙》

## 阅读原文
森林翼龙的翼展虽然仅为 25 厘米，但科学家分析认为它已经成长发育为一只能够展翅飞翔的年轻体。这一新翼龙化石因此成为**迄今为止**发现的世界最小的无齿翼龙。

## 练习题目
**【问】画线词“迄今为止”一词能否去掉？为什么？**

1、选择：
(1) 判断文体（打“√”）：A. 记叙文 B. 说明文 C. 议论文 D. 非连续性文本
(2) 看分值判难易（难的分点答，易的简单答）：（A. 难 B. 易）

2、按要求填空：
[ 审题目 ] ➔ [ A词能否删除 ] ➔ [ 不能 ] ➔ [ A词意思 ] ➔ [ 句子意思 ] ➔ [ 若删去，则与客观事实不符 ] ➔ [ 体现了说明文语言准确性 ]

答：__________________________________________________________________________

---

## 参考答案
**不能去掉。** “迄今为止”从时间上进行限制，更准确地表达出森林翼龙是目前发现的最小的翼龙，不排除今后还有更小的翼龙发现的可能性。如果去掉，就与原意不符，所以不能去掉，这体现了说明文语言的准确性。
